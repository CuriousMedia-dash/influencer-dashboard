TEAM SCREEN — setup
===================

The "Create user" button is now "Users". Same button, same place.

WHAT IT DOES
------------
- Lists everyone with portal access, their level, and when they last
  signed in
- Add someone (same form and rules as before), and tick Admin while
  creating if you want
- Switch anyone between Member and Admin, any time
- Set someone's password directly — type one or hit Generate, save, then
  optionally open a mail draft with the new password in it
- Remove someone's access

You can't change or remove your own access from here.

There is no "send them a reset link" for team members. You set the
password and tell them. Reset links stay a brand-side thing — the brand
login's "Forgot password" already mails one automatically.

WHAT TO DEPLOY
--------------
One function. In Supabase: Edge Functions -> Deploy a new function ->
name it exactly:

    manage-users

Paste in everything from supabase/functions/manage-users/index.ts.

Its secrets (Edge Functions -> manage-users -> Settings) only need:

    SUPABASE_URL                 (normally already set)
    SUPABASE_SERVICE_ROLE_KEY    (normally already set)

Resend keys are NOT needed here anymore — nothing on this screen sends
mail by itself. That's what the "Mail didn't send" message was about.

ALSO REDEPLOY
-------------
    send-acquisition-mail

It now accepts a reply-to address, so replies from creators land in the
inbox of whoever pressed send.
