TEAM SCREEN — what changed and what to do
=========================================

The "Create user" button is now "Users". Same button, same place; it
opens a fuller screen instead of just the create form.

WHAT'S NEW
----------
- Everyone with portal access is listed, with their level and when they
  last signed in
- Switch anyone between Member and Admin, any time
- Mail a password reset link (points at https://creators.curiousmedia.in)
- Remove someone's access
- Creating a user works exactly as before — same form, same rules, same
  create-team-user function. You can now also tick Admin while creating,
  instead of adding them to the admins table by hand afterwards.

You can't change or remove your own access from here. That's the one
mistake that would lock every admin out.

WHAT YOU NEED TO DO
-------------------
Deploy ONE new function. Creating users already had its own function;
this one covers the parts that didn't exist yet — listing people,
changing roles, resetting passwords, removing access. All of those need
the service role key, which can't live in the browser.

In Supabase: Edge Functions -> Deploy a new function -> name it exactly:

    manage-users

Paste in everything from supabase/functions/manage-users/index.ts.

Check its secrets afterwards (Edge Functions -> manage-users ->
Settings):

    SUPABASE_URL                 (normally already set)
    SUPABASE_SERVICE_ROLE_KEY    (normally already set)
    RESEND_API_KEY               (only for reset-link mail)
    RESEND_FROM                  (only for reset-link mail)

If the Resend ones are missing, everything still works except emailing
the reset link — it gets copied to your clipboard instead so you can
send it yourself.

Until this function is deployed, the Users screen will show an error
where the list should be. Creating a user keeps working regardless,
since that runs on the function you already had.
